# Let it Go

เกมจำลองชีวิตคนทำงาน 1 เดือน เล่นด้วย**มือจริงผ่านกล้อง** (MediaPipe) ถ้าไม่มีกล้องก็เล่นด้วยเมาส์ได้

## เกมเกี่ยวกับอะไร

ชีวิตวัยทำงานต้องหาเงิน แต่งานก็กินพลังงานและความสุข ถ้าทำแต่งานจะหมดไฟ ถ้าเที่ยวเล่นมากเงินก็หมด
ผู้เล่นต้อง "ปล่อยวาง" (Let it Go) ให้พอดี รักษาสมดุลของ **เงิน ความสุข พลังงาน** ให้อยู่รอดจนครบเดือน

กลางเดือนมี **Event สงกรานต์พักใจ** ช่วงพักจากงาน ได้ไปเล่นน้ำ กลับบ้านต่างจังหวัด และเติมความสุขก่อนกลับไปทำงานต่อ

## เปิดเกม (โฟลเดอร์ build)

1. คัดลอกโฟลเดอร์ `Builds/Windows` ไป**ทั้งโฟลเดอร์** ห้ามแยกไฟล์ออกมา
2. ต่อกล้อง (webcam หรือ Orbbec Gemini) ก่อนเปิดเกม
3. ดับเบิลคลิก **`Start Hand Tracker.bat`** ก่อนเข้าเกมทุกครั้ง
   - รอจนหน้าต่างกล้องขึ้นและเห็นภาพจากกล้อง (ครั้งแรกอาจใช้เวลา 10–30 วินาที)
   - เปิดหน้าต่างกล้องค้างไว้ตลอดตอนเล่น ถ้าปิด เกมจะสลับไปใช้เมาส์
4. ดับเบิลคลิก **`Let it Go.exe`** เพื่อเข้าเกม
5. ฉาก Title จะให้เช็คมือ: ขยับมือไปมาจนหลอดเต็ม แล้วกำมือค้างไว้จนหลอดเต็ม

ไม่ต้องติดตั้ง Python เพราะ build มี Python 3.13 และ MediaPipe อยู่ในโฟลเดอร์ `HandTracker/python` แล้ว

**เล่นด้วยเมาส์:** เปิด `Let it Go.exe` ตรงๆ ไม่ต้องเปิด bat ขยับเมาส์ = ขยับมือ, คลิกซ้ายค้าง = กำมือ

## ระยะเล่น

| รายการ | ค่า |
|---|---|
| ระยะจากกล้องถึงมือ | **0.5 – 1.5 m** (แนะนำประมาณ 1 m) |
| มือนอกระยะ | เกมไม่รับ (กันคนเดินผ่านด้านหลัง) |
| จำนวนผู้เล่น | 1 คน ใช้มือข้างเดียว (เกมจับมือแรกที่เข้าระยะ) |

ระยะคำนวณจากขนาดมือในภาพ จึงคลาดเคลื่อนได้เล็กน้อย ถ้าเกมไม่รับมือ ให้ขยับเข้าหรือถอยห่างจากกล้อง
ยืนให้มือทั้งมืออยู่ในภาพ และให้แสงส่องหน้ามือ ไม่ย้อนแสง

## วิธีเล่น

| ท่า | ผล |
|---|---|
| ขยับมือ (แบมือ) | เลื่อนเคอร์เซอร์มือบนจอ |
| กำมือ ตรงไอคอน | คว้าไอคอน ได้ผลของไอคอนนั้น |

ไอคอนกิจกรรมตกลงมาจากด้านบน เลือกคว้าไอคอนที่ต้องการ:

| ไอคอน | สี | ผล | ตัวอย่าง |
|---|---|---|---|
| งาน | แดง | **+เงิน** แต่ −ความสุข −พลังงาน | ทำงาน, เขียนโค้ด, ประชุม, ตอบอีเมล |
| พักผ่อน | เหลือง | **+ความสุข** แต่ −เงิน | ออกกำลังกาย, เล่นเกม, ฟังเพลง |
| ฟื้นพลัง | เขียว | **+พลังงาน** | กินข้าว, นอนหลับ |

- ทั้ง 3 หลอดลดลงเองตลอดเวลา และลดเร็วขึ้นช่วงปลายเดือน
- 1 เดือน = 3 นาที มุมจอแสดงวันที่ 1–30

**ชนะ:** อยู่รอดจนครบ 30 วัน

**แพ้:**
- เงินหมด
- พลังงานหมด

**หมดไฟ:** ถ้าความสุขเหลือ 0 ทำงานจะได้เงินแค่ครึ่งเดียว ต้องไปพักผ่อนก่อน

### Event สงกรานต์พักใจ

- เริ่มเมื่อเล่นไป 1 นาที (เวลาเหลือ 2:00) ยาว 1 นาที
- ไอคอนเปลี่ยนเป็นกิจกรรมสงกรานต์ เช่น เล่นน้ำ, นวด, กินข้าวแช่, นอนกลางวัน, สรงน้ำพระ ให้ความสุขและพลังงาน
- เงินไม่ลดช่วง Event
- คว้าติดกันได้**คอมโบ** คอมโบหลุดเมื่อไม่ได้คว้าไอคอนเลย 3 วินาทีเท่านั้น ปล่อยไอคอนตกหรือกำพลาดไม่ทำให้หลุด คอมโบสูงยิ่งได้ผลมากขึ้น และมีไอคอน "ได้โบนัส" กับ "ญาติให้ตังค์" ตกมาให้เงิน
- จบ Event ได้โบนัสเงินตามคอมโบสูงสุด และช่วงทำงานหลัง Event ความสุขจะขึ้นง่ายขึ้น

## ปิดเกม

1. ปิดเกม `Let it Go.exe`
2. กด **Esc** ที่หน้าต่างกล้อง เพื่อปิดตัวจับมือ

## ปรับตัวจับมือ

ส่งค่าต่อท้ายตอนเปิด bat ผ่าน Command Prompt เช่น:

```
"Start Hand Tracker.bat" --min-dist 0.8 --max-dist 2.0
```

| ตัวเลือก | ความหมาย |
|---|---|
| `--min-dist` / `--max-dist` | ระยะเล่นใกล้สุด / ไกลสุด หน่วยเมตร (ค่าเริ่มต้น 0.5 / 1.5) |
| `--camera N` | เลือกกล้องตัวที่ N (เริ่มที่ 0) |
| `--source webcam` / `--source orbbec` | บังคับชนิดกล้อง (ค่าเริ่มต้น `auto`: ลอง Orbbec ก่อน แล้วค่อย webcam) |
| `--zoom 1.5` | ซูมภาพกล้อง ใช้เมื่อผู้เล่นยืนไกล |

## ปัญหาที่พบบ่อย

| อาการ | วิธีแก้ |
|---|---|
| เกมขึ้นว่า "ไม่พบตัวจับมือ ใช้เมาส์แทน" | ปิดเกม เปิด `Start Hand Tracker.bat` รอหน้าต่างกล้องขึ้น แล้วค่อยเปิด `Let it Go.exe` ใหม่ |
| หน้าต่างกล้องดำหรือไม่ขึ้น | ปิดโปรแกรมอื่นที่ใช้กล้อง (Zoom, Teams, Discord) หรือลอง `--camera 1` |
| bat ขึ้นว่า `HandTracker\python is missing` | คัดลอกโฟลเดอร์ build ไม่ครบ ให้คัดลอก `Builds/Windows` ใหม่ทั้งโฟลเดอร์ |
| เคอร์เซอร์มือไม่ขยับ | ตรวจว่ามืออยู่ในระยะ 0.5 – 1.5 m และอยู่ในภาพกล้อง |
| Windows Firewall ถาม | กด Allow (ตัวจับมือส่งข้อมูลให้เกมทาง UDP port `5065` บนเครื่องเดียวกัน) |

## สำหรับผู้พัฒนา (เปิดใน Unity)

- Unity `6000.3.22f1`
- ก่อนกด Play ให้ดับเบิลคลิก `Start Hand Tracker.bat` ที่โฟลเดอร์โปรเจกต์
  - ครั้งแรกจะสร้าง `HandTrackerEnv` และติดตั้ง MediaPipe (ต้องมี Python 3.11–3.13 และอินเทอร์เน็ต)
- Build Windows ตามปกติ (File > Build Profiles) ออกไปที่ `Builds/Windows`
  - หลัง build เสร็จ `Assets/Scripts/Editor/HandTrackerBuildBundle.cs` เรียก `Tools/bundle_hand_tracker.py` ให้อัตโนมัติ
  - สคริปต์คัดลอก Python, MediaPipe, `Start Hand Tracker.bat` และ README นี้ลงโฟลเดอร์ build
- โฟลเดอร์ `Let it Go_BurstDebugInformation_DoNotShip` ไม่ต้องส่งไปพร้อมเกม
